It is a smart Travel Booking System  which uses both SQL and MongoDB to efficiently manage different types of data. MongoDB handles flexible data such as chatbot conversations, voice queries, search history, travel API responses, and user preferences. Its document-based structure is suitable for dynamic and semi-structured information. SQL databases such as MySQL or PostgreSQL manage structured and transactional data, including user accounts, bookings, payments, reservations, and ticket details. SQL provides relational data management, consistency, and transaction support for critical operations. The Node.js and Express backend communicates with both databases according to data requirements. This hybrid database architecture improves flexibility, scalability, organization, and reliability while demonstrating the practical integration of relational and NoSQL databases in a modern full-stack travel booking application.
